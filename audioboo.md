# Интеграция Audioboo.org

## Текущий статус

Поддержка `audioboo.org` реализована. Пользователь может вставить ссылку вида:

```text
https://audioboo.org/fenezi/108102-ivanov-aleksej-nevjanskaja-bashnja.html
```

SonicBook сам определяет страницу Audioboo, ищет ZIP-ссылку, декодирует redirect-параметр и передает скачивание в pipeline `DIRECT_ZIP:`. Для таких книг детальные тайминги глав на странице обычно отсутствуют, поэтому финальный ZIP воспроизводится через встроенный playlist mode: приложение безопасно извлекает архив по требованию и проигрывает файлы внутри последовательно.

## 1. Анализ ресурса
**Сайт:** `https://audioboo.org/`
**Пример страницы:** `https://audioboo.org/postapakalipsis/113245-ivanov-aleksej-vegetacija.html`
**Методы получения:** Прямое скачивание ZIP-архива через редирект (Base64).

### Особенности:
- Ссылки на ZIP скрыты за `engine/go.php?url=[BASE64_URL]`.
- ZIP-архивы часто хостятся на внешних ресурсах (например, `archive.org`).
- На странице обычно есть название, автор и обложка.

---

## 2. Scraper (`scraper.py`)

Реализованный блок в `get_book_info()` распознает `audioboo.org`.

### Шаги скрапинга:
1. **Title:** Извлечение из тега `<h1>`.
2. **Cover:** Использование существующей функции `extract_cover_url`.
3. **ZIP URL:** 
    - Поиск ссылки, содержащей текст "Скачать ZIP" или аналогичный.
    - Извлечение параметра `url` из `engine/go.php?url=...`.
    - Декодирование Base64 (например, `aHR0...` -> `https://archive.org/.../file.zip`).
    - Использование `httpx(follow_redirects=True)` для финального скачивания.
4. **Chapters:** На страницах audioboo часто нет детального тайминга глав. В этом случае мы будем полагаться на **Playlist Mode** (автоматическое сканирование файлов внутри ZIP при воспроизведении).

---

## 3. Processor (`processor.py`)

Реализован протокол `DIRECT_ZIP:`, аналогичный существующему `DIRECT_URLS:`.

### Логика обработки:
1. Если `m3u8` начинается с `DIRECT_ZIP:`, `processor.py` передает работу в `_handle_direct_zip_download()`.
2. ZIP скачивается как один большой файл через общий single-file downloader.
3. После успешной загрузки ZIP валидируется, переносится в `DOWNLOADS_DIR`, и рядом создается sidecar `.json` с метаданными.

---

## 4. Использование существующих сервисов
- **`zip_service.py`**: Приложение уже умеет извлекать ZIP-архивы "на лету" и строить плейлист из файлов `.mp3`/`.m4a` внутри. Это идеально подходит для Audioboo.
- **`bookmark_service.py`**: Поддержка закладок для ZIP уже реализована (сохранение индекса трека и позиции).

---

## 5. Пользовательский сценарий

1. Вставить ссылку на страницу Audioboo в SonicBook.
2. Выбрать режим скачивания. Для Audioboo фактический результат обычно остается ZIP, потому что источник предоставляет готовый архив.
3. Запустить скачивание.
4. После завершения открыть книгу из локальной библиотеки.
5. SonicBook извлечет ZIP по требованию и покажет playlist/главы из файлов внутри архива.

## 6. Ограничения

- Если на странице нет рабочей ZIP-ссылки, приложение вернет ошибку поиска аудиопотока.
- Если в ZIP нет поддерживаемых аудиофайлов, архив не будет полезен для playlist playback.
- Тайминги глав берутся не со страницы Audioboo, а из структуры файлов внутри ZIP.
